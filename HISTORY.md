# foodwise-india/  (aka "Jaano") — full history

Consumer-health app for understanding packaged foods sold in India — searchable food catalog, ingredient-concern decoder, side-by-side healthier-alternative swaps, corporate-parent directory, a daily food diary, and a **personal health/BMI engine**. **Live: https://kartikeyjaiswal42-sudo.github.io/foodwise-india/** (repo `kartikeyjaiswal42-sudo/foodwise-india`). Brand name in UI = **"jaano"** (title "Jaano — Know what you eat").
- **STACK = Next.js 15 App Router, static export (migrated from Vite 2026-06-11).** React 19 + `lucide-react`, no backend (localStorage). Layout `src/app/layout.js`, the whole SPA is one `'use client'` page `src/app/page.js`; components in `src/components/`, data in `src/data/`, pure logic in `src/lib/`. Global CSS = `src/app/globals.css` (font `@import` MUST stay first line). `next.config.mjs`: `output:'export'`, `images:{unoptimized:true}`, `trailingSlash:true`, and **`basePath:'/foodwise-india'` only when `PAGES_BASE=1`** (so a plain `next build` serves from root for local testing, deploy build adds the subpath). Run: `npm install` → `npm run dev`. **localStorage GOTCHA:** never read localStorage in a `useState` initializer — static prerender has no `window` and the export crashes; `page.js` hydrates log+profile in a mount `useEffect` gated by a `hydrated` flag. Components used only by the client page don't need their own `'use client'`.
- **Health / BMI engine (2026-06-11):** new "My Health & Goals" nav → `src/components/Profile.jsx` (height/weight/age/sex/activity + goal lose|maintain|gain). `src/lib/health.js` (pure) computes BMI + category, BMR (Mifflin–St Jeor), TDEE (activity factor), goal-adjusted `calorieTarget` (lose −500, gain +400, floor 1200), and **personalised daily ceilings** `{calories,sugar,sodium,satFat}` (sugar = 5/7/10 % energy by goal ÷4; satFat 7/10 % ÷9; sodium 1800 lose / 2300 else). Profile persists to localStorage `jaano-profile-v1`; `page.js` passes the derived `limits` into Dashboard/Diary/ProductDetail (with `DEFAULT_LIMITS` fallback so it works with no profile). Dashboard shows a live **calorie budget** bar (consumed vs target, goal-labelled). `HealthReport.jsx` organ-risk model is now **data-driven** (`exposureOf(product)` derives maida/palm/carrageenan/maltodextrin flags from real ingredient text + sugar/sodium/satFat from nutrition) instead of the old hardcoded per-id weights table.
- **Ingredient intelligence + Healthy Swaps + diary remove (2026-06-11):** `src/lib/ingredientClassify.js` = pure `classifyIngredient(str)` → `{verdict good|neutral|bad, label, why, group}` via ~60 ordered keyword rules + an `ADDITIVE_VERDICT` INS/E map. **KEY gotcha:** Indian labels write bare additive numbers like "flavour enhancer (635)" WITHOUT an INS/E prefix → `additiveCodes()` only extracts 3-digit codes when the string has an additive-class word (colour/flavour/enhancer/preservative/raising agent/…) or INS/E prefix, and ignores numbers followed by a unit (mg/g/%) so "(200 mg)" isn't read as additive 200. Watch the `\braisins?\b` boundary — bare `raisin` matched "rai**sin**g agent". Occurrence split ≈ good 39 / neutral 38 / bad 24 %. Also `buildIngredientIndex(products)` (frequency-ranked distinct ingredients) and `ingredientQuality(product)` (good/neutral/bad tally). **IngredientGuide.jsx** rebuilt into a searchable/filterable DB of every distinct ingredient (good/neutral/bad tabs + counts) on top of the 4 watchpoint cards. **ProductDetail** colour-codes every ingredient chip by verdict (`v-good/v-neutral/v-bad`) + a decoder popover (rich `ingredientsDb` detail when available, else the classifier `why`). **New `HealthySwaps.jsx`** view (wired to the "Healthy Swaps" nav `view==='swaps'`) — processed products paired with a higher-scoring same-category `alternative`, sorted worst-first. **Diary** got an ingredient-quality bar (good/neutral/bad for the day); per-entry **remove** = the trash button on each timeline card (`onDeleteLog(item.id)` → `deleteLog` in page.js, already worked).
- **REAL-DATA CATALOG, 998 products (2026-06-10):** user demanded "ALL products of the top-10 India packaged-food companies, each with the REAL packaging photo (no diagrams)." Source = **Open Food Facts** (openfoodfacts.org, ODbL) — the only free dataset with real front-of-pack photos + ingredients + per-100g nutrition for India-market SKUs. Built by **`scripts/build-catalog.mjs`** (run: `node scripts/build-catalog.mjs` → overwrites `src/data/foodDatabase.js`). It queries `world.openfoodfacts.org/api/v2/search?brands_tags=<brand>&countries_tags=en:india&states_tags=en:front-photo-selected` (the state filter guarantees `image_front_url` exists), paginates (≤4×100/brand), polite **6.5 s delay + 429 backoff** (OFF limit ~10 req/min → full run ~15 min), across a `COMPANIES` map of ~76 brand slugs → 10 parents (Nestlé/Britannia/Haldiram's/ITC/Parle/Amul/PepsiCo/Mother Dairy/Tata/MTR-Mondelez). Per product it derives: `score`/`grade` (from `nutriscore_grade`, else heuristic on sugar/sodium/satFat + NOVA), `concerns` (FSSAI/WHO per-100g thresholds + additives_tags), `nutrients{sugar,sodium,satFat}` (sodium = sodium_100g×1000 or salt→/2.5), `ingredients` (from ingredients_text), `price` (ESTIMATE from quantity×category rate — UI labels it "est. cost"), and a post-pass **auto-assigns `alternative`** = highest-scoring same-category product (score +8) with a real `alternativeCompare`. **Schema contract the components require (don't break):** `nutrients` must contain ONLY keys sugar/sodium/satFat (ProductDetail does `metricMeta[metric]` → undefined key crashes); `calories` must be a number not null ("null kcal" renders); `concerns`/`ingredients` arrays may be empty; `alternativeCompare` always present. **Expanded + cleaned (2026-06-11):** ~138 brand slugs, `MAX_PAGES=6`, a **name-quality filter** (`goodName` rejects brand-only / "Maggi 140g" size-only / mostly-numeric names), and **dual image sizes** (`image`=400px for cards, `imageLarge`=`.full.jpg` for the ProductDetail hero via `large` prop on shared `ProductPack`, which falls back large→400→illustrated pack). Result: **887 cleaned products** (Britannia 154, ITC 143, Nestlé 140, Haldiram's 111, Amul 93, Tata 87, Parle 74, PepsiCo 42, MTR/Mondelez 39, Mother Dairy 4 — counts vary with OFF data depth × quality filter). Categories now also include Breakfast + Ready meals. Images `loading="lazy"`. **CAVEAT (told to user):** "ALL" = all India SKUs that exist in Open Food Facts WITH a real front photo — no public source has literally every SKU; prices are estimates. Re-run the script to refresh/expand (drop more brand slugs into `COMPANIES`). Backups of the prior data are `src/data/foodDatabase.js.bak-*` (gitignored). The old 32 curated products (with hand-written swaps) were replaced — `ingredientsDb.js` hazard registry is retained (ProductDetail still decodes ingredients against it). **Verified:** 998 cards render, real photos decode (sampled 21/21 image URLs HTTP 200 JPEG), detail/search/diary work, 0 console errors.
